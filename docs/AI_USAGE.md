# AI assistance statement

This personal project is developed collaboratively with an AI coding assistant. AI assistance covers
architecture discussion, implementation, test construction, debugging, documentation and interpretation
of experiments. The human project owner chooses goals, configures credentials, runs/reviews experiments
and remains responsible for published claims.

The application's DeepSeek runtime calls are a separate mechanism from development assistance. Runtime
calls are logged and budgeted by the application. Offline mock policies and replayed responses are
explicitly labeled; neither is presented as a newly executed live-LLM experiment. No fabricated benchmark
results should be published. A skipped Docker/live test is not evidence that the feature works end to end.
