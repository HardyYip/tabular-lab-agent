## 独立复核结果

- Windows：49 项通过、0 跳过，其中 45 项离线、4 项真实 Docker 测试。
- Linux：无网络、只读源码容器内 45 项离线测试通过。
- Docker 用例覆盖训练/导出/预测、失败修复与成功源码反馈、默认 CatBoost 输出、超时后清理。
- 新进程能自动读取保存的密钥；模拟 HTTP 头检查和后续真实 API 调用均已通过。
- 所有公开结果均由实际日志与预测产物核对；未把 replay 当真实 API 实验。
- 完整对照的 74 次 API 调用估算 0.92692296 元；本轮另有三次 V2 运行，新增估算总费用
  **1.06106328 元**。此前的原始 demo 与 V1 smoke 费用不重复计入本轮。

## 如实保留的结论

Agent 在 Breast Cancer、Wine 上与已很强的基线持平；Wine Quality 均值略低于随机搜索；
Adult 均值较高。只有三个种子，不能据此声称普遍更优或统计显著。
实验期间部分任务并行运行，耗时用于成本和工程观察，不用于严格的速度优劣结论。

原始 demo 的第三段代码通过更换算法成功，不能算修复了 CatBoost 的具体根因。
实际根因已通过对照确认并在执行器修复。新的成功源码记忆 demo 测试分数更低，也已完整保留。
V2 真实数据实验主要验证功能，候选空间与 V1 不同，不能直接作公平性能比较。
